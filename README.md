# HVAC PROF

Sitio institucional multipágina de **HVAC PROF**, especialista en fabricación y montaje de conductos de aire acondicionado, ventilación y extracción.

**Demo publicada:** [estudioideamos.github.io/hvac-prof-demo](https://estudioideamos.github.io/hvac-prof-demo/)

## Alcance

Presentación institucional, servicios de diseño y fabricación computarizada, productos, piezas estándar y especiales, sistemas de unión, proyectos y contacto. La experiencia es responsive y cuenta con navegación accesible.

## Tecnología

Sitio estático desarrollado con HTML, CSS y JavaScript. No tiene dependencias de ejecución y utiliza recursos locales y una política de seguridad de contenido.

## Estructura

Las páginas se encuentran en la raíz. `assets/` contiene recursos; `styles.css` define el sistema visual y `script.js` concentra la interacción.

## Desarrollo local

```powershell
./serve.ps1
```

o bien:

```bash
node serve.mjs
```

## Publicación

Se publica directamente desde `main` con GitHub Pages; no requiere build.

## Control de calidad

Antes de publicar se deben revisar enlaces entre páginas, formularios, navegación móvil, imágenes, política CSP y comportamiento con movimiento reducido.
